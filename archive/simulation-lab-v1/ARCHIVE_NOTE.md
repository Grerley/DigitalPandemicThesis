# Archived: original Interactive Simulation Lab (version 1)

This folder is a frozen copy of the first version of the Interactive Simulation Lab, kept for reference only.

It was built on the original version of the thesis. Its parameter values (monthly rates calibrated to the
earlier targets), its starting state, its intervention effects and its cost framing in rand come from that
version and are **not** consistent with the current thesis, the research proposal or the papers. It is not
deployed and should not be cited for any result.

The current lab is in `app/`. The same version is also available at the git tag `simulation-lab-v1`.

To run this archived copy locally: `cd archive/simulation-lab-v1 && python3 -m http.server 8000`.
